# ProyectoAnalitica1

Este repositorio contiene un notebook de análisis de datos con Python.

##  Archivos
- `analisis.ipynb`: Notebook principal con ejemplos de análisis y visualización.
- `requirements.txt`: Librerías necesarias para ejecutar el notebook.

##  Abrir en Google Colab
Haz clic en el siguiente botón para abrir el notebook directamente en Colab:

[![Abrir en Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ltamjacinto18/ProyectoAnalitica1/blob/main/analisis.ipynb)

##  Instrucciones
1. Abre el notebook en Colab usando el botón de arriba.  
2. Ejecuta las celdas paso a paso para reproducir el análisis.  
3. Si necesitas instalar dependencias adicionales, usa el archivo `requirements.txt`.
